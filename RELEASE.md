First release of the Delta source apps: YouTube (search via own API key or public Piped/Invidious, or links), SoundCloud (links + oEmbed) and Spotify (links/URIs + oEmbed). Items are sent to the player with `media.play` / `media.enqueue` intents; they follow the global Delta skin. Requires Delta UI 0.3.0 hosts and Delta Media 0.2.0. Verify SHA256SUMS before importing the .delta-app packages.
